# BUSI4543 Corporate Finance - TSLA Team Portfolio

Interactive single-page team portfolio for the BUSI4543 (Corporate Finance) group project.

Open index.html in a browser. The page is fully self-contained (Tailwind CSS is inlined), so it works offline.
